# 小米手机与宝马 iDrive 7 蓝牙兼容测试

本分支基于 V46 中控公开试用版及已有的蓝牙兼容诊断代码。一次反馈使用 Xiaomi 17 Pro Max、Android 17（SDK 37）和 V46 公测版：启动前车机 A2DP 在线，应用按原策略发起断开，随后三次 RFCOMM 连接失败；日志未包含失败的具体异常信息。车主反馈启动后蓝牙断开。现有材料尚不能确定 RFCOMM 失败的具体原因。

11 月 19 日的复测已开启保留系统蓝牙；一次服务发现未列出目标服务，之后多次 RFCOMM 连接快速失败。Android 的服务发现可能返回缓存，该次结果需要结合车机侧操作继续核对。

## 本次测试改动

- 小米独立 debug 测试包在没有已保存偏好时默认开启“保留系统蓝牙连接（兼容测试）”，关闭后仍可使用原有策略。此前保存的选择优先，因此安装后请确认开关状态。
- 保留模式下，启动连接以及应用内配对完成后的处理均不主动执行系统蓝牙断开；SDP 查询结果用于诊断，不阻止显式选择车机后的 RFCOMM 尝试。
- 记录蓝牙服务探测和 RFCOMM 失败阶段、有限分类和耗时，不输出平台异常原文。蓝牙服务发现可能返回系统缓存结果，不能据此单独判定车机不支持。
- 在兼容测试模式下，对已选车机进行有限次数的间隔复查，方便观察车机侧界面切换后的服务发现情况；混合的“连接关闭或超时”错误不再简单标为确定超时。
- 沿用此前测试分支的敏感日志收敛措施；其它日志仍可能包含设备名称、地址或网络信息，分享前应检查。

## 停车测试

1. 安装独立测试包，不必卸载 V46 公测版；退出原版后单独为测试版授权蓝牙、Shizuku 等所需权限，需要车机声音时按提示授予投屏权限。
2. 在连接准备页确认“保留系统蓝牙连接（兼容测试）”已开启，并选择已配对的目标车机。修改开关后需断开 CarDeck 并重新启动连接。
3. 点击启动，在车机“移动设备”中打开或选择 CarPlay 连接入口，等待约 60 秒；观察系统蓝牙是否保持连接、车机是否显示手机和 CarPlay 画面，并记录具体提示。
4. 如仍失败，请导出测试版日志，并注明开关状态及车机和手机各自的提示。不要向公开仓库提交未检查的原始日志。

该版本用于排查，不把蓝牙连接保持或车机投屏视作已在小米设备上验证成功。
