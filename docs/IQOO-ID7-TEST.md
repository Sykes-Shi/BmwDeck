# iQOO 与宝马 iDrive 7 首次 CarPlay 配对测试

11 月 23 日，iQOO（Android 16）安装了首次配对测试 APK。日志先记录选定一台已配对的宝马，随后进入普通重连。已保留通话和音频蓝牙，等待车机回连 30 秒，之后 65 次主动投屏蓝牙连接均失败。日志未经过「配对并连接」的配对前监听。车机照片在 Apple CarPlay 搜索设备页面。

首配引导版在首页增加「配对或重连」入口。选中的宝马还有系统蓝牙配对时，App 会打开提示，可以前往系统蓝牙设置，或明确选择沿用旧配对重连。首次配对时，App 先为选中的车机开启投屏蓝牙监听，再请 Android 发起系统配对。配对成功后沿用已开启的监听。

1. 停车，安装这次 ZIP 内的 APK，可覆盖此前的 iQOO 首次配对测试版。开启手机蓝牙和 Wi-Fi，确认 Shizuku 和触控服务就绪。
2. 点手机首页「配对或重连」。如果出现「这辆车已配对」，点「去手机蓝牙设置」。在手机和车机分别取消这部 iQOO 与这辆宝马的旧配对。回到 CarDeck，再点「配对或重连」。
3. 车机停在「移动设备 → 新设备 → Apple CarPlay」的搜索页。手机点「查找车机」，在「附近的设备」找到宝马，点「配对并连接」。在两边核对并确认配对码，如车机提示使用 Apple CarPlay，按提示确认。
4. 等约一分钟，如果未出现投屏，导出本次日志并记录车机停在哪一页。新日志可按「CarPlay 蓝牙服务已就绪」和「已发起配对」两条事件复核首配流程。

11 月 23 日的旧配对重连结果已核对。配对前监听能否在这台车上建立投屏，待实车验证。
