# iQOO 与宝马 iDrive 7 首次 CarPlay 配对测试

11 月 22 日复测使用 iQOO（Android 16）和上一轮回连测试版。手机与车机完成系统蓝牙配对约 13 秒后，CarDeck 才启动投屏蓝牙监听。允许蓝牙可见 60 秒且优先等车机回连的流程已经执行。后续主动连接全部失败，日志未记录车机回连或热点配置。车机照片停在 Apple CarPlay 搜索设备页面。

这版把手机端投屏蓝牙监听提前到系统配对之前，让车机在建立配对时就能发现服务。用户仍需在手机和车机上确认系统配对。配对完成后继续用同一个监听，只接受所选目标，并继续优先等车机回连。首次测试保留系统蓝牙，先验证能否显示投屏画面。

1. 停车，安装这次压缩包内的 APK。它可以覆盖上一版 iQOO 回连测试包。开启手机蓝牙和 Wi-Fi，确认 Shizuku 和触控服务显示就绪。
2. 如果两边还存有这部 iQOO 与这辆宝马的旧配对，只取消这对记录。车机打开「移动设备 → 新设备 → Apple CarPlay」，停在搜索页面。
3. 在 CarDeck 的「连接准备 → 选择设备」中，从附近设备列表选宝马，点「配对并连接」。在两边核对并确认相同的配对码。车机如果提示使用 Apple CarPlay，按提示确认。保持手机亮屏，等待约一分钟。
4. 如果仍未显示投屏，导出这次日志并记下车机停在「搜索设备」「确认配对」还是「正在建立连接」。可用同一车原生 iPhone 的连接结果作对照。

已配对设备的「启动连接」仍沿用回连优先策略。此版修正的是应用准备投屏服务和系统配对的先后顺序，实际车机结果待复测。
