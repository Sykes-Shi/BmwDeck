# OPPO / iDrive 8.5 蓝牙兼容测试

本分支基于 V46 中控公开试用版，用于排查手机与车机在蓝牙 iAP2 RFCOMM 建链阶段的兼容问题。反馈设备为 OPPO Find X10，截图显示 ColorOS 17（PMW110_17.0.1.202），日志记录 Android 17（SDK 37）。普通蓝牙可以识别，但 CarPlay 连接未建立；一次日志中 Shizuku 和投屏授权已就绪，主动 RFCOMM 连接多次失败，尚未取得足够证据确定失败原因。

## 测试版变化

- 连接准备页增加“保留系统蓝牙连接（兼容测试）”。默认关闭，沿用原有策略；开启后在下次连接中保留车机通话和媒体蓝牙连接，并记录所选车机的 SDP 探测状态，探测不作为明确指定车机的连接拦截条件。
- 记录蓝牙服务探测结果、RFCOMM 创建或连接的失败类别和耗时；不记录系统异常原文。修正自动候选设备的 iAP2 UUID 判断。
- 0x4301 日志只保留参数编号、长度及必要的存在状态，底层 iAP2 原始字节和会话读写密钥不再写入日志；其余日志仍可能包含设备名称、地址或网络信息，分享前应检查。

## 停车对照步骤

1. 安装蓝牙兼容测试版。该 debug 构建使用与 V46 公测版不同的应用 ID，可并存；只运行一个版本，并为测试版单独授予 Shizuku、蓝牙和投屏权限。
2. 确认手机与目标宝马已配对，在连接准备中选择该车机，并在车机“移动设备”界面尝试启动 CarPlay。
3. 首次保持兼容开关关闭，启动连接并等待约 60 秒，记录车机界面及结果，导出日志。
4. 断开连接，开启“保留系统蓝牙连接（兼容测试）”，重新启动连接并等待约 60 秒，再导出一份日志。
5. 分别注明两次开关状态、车机界面表现和测试时间，便于对照 SDP 状态及 RFCOMM 阶段、耗时和失败类别。

两次结果用于定位兼容问题；车机是否显示 CarPlay、成功投屏和音频表现均以实车结果为准。不要向公开仓库提交未检查的原始日志。
