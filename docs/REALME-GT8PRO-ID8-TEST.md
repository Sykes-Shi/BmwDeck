# 真我 GT8 Pro / iDrive 8 回连测试

现场日志来自真我 GT8 Pro（RMX5200、Android 17），车主报告车机为 iDrive 8。早期自动发现多次超时。完成系统配对后，旧测试版保留普通蓝牙并向指定宝马发起连接，录得 17 次 RFCOMM 失败，没有收到车机回连或热点配置。

该测试包基于中控兼容诊断分支。选择已配对的宝马时不主动进行附近设备扫描，默认保留蓝牙通话和音频。按 Android 系统提示批准后，手机临时可见 60 秒。监听启动后先给车机 60 秒发起连接，之后手机才尝试主动连接指定的车机。已选车机的 SDP 缓存仅用于观察。主动连接建立后若 12 秒仍未收到对端数据，释放该连接并继续监听。既有日志还可区分连接阶段和系统提供的错误码。

1. 停车后退出其他 CarDeck 版本的连接，打开「CarDeck BMW 真我 GT8 Pro ID8 测试」，授权附近的设备和 Shizuku。
2. 在「连接准备」中选择这台已配对的宝马，保持「保留系统蓝牙连接」开启。「启动连接」时选「仅视频」，按系统提示允许手机临时蓝牙可见。
3. 在宝马「移动设备」里选这部手机，有 Apple CarPlay 选项就点它。若该设备页没有投屏入口，打开「连接新设备」观察车机能否发现手机。等待约 90 秒，检查是否进入投屏。
4. 若仍失败，导出本次运行日志，附上车机最后一个页面或提示。分享前请脱敏设备名称、地址和网络信息。

参考：[BMW 配对指南](https://faq.bmwusa.com/s/article/BMW-setting-up-Apple-CarPlay-bDaHU)、[Android 蓝牙发现说明](https://developer.android.com/develop/connectivity/bluetooth/find-bluetooth-devices)。
