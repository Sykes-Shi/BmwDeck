# BmwDeck 中控版首次连接

> BmwDeck 安装在 **Android 手机**上。宝马车机须已支持无线 Apple CarPlay。请在停车时完成首次配置，保留原车导航作为备用。

## 先选对版本

- **V58 中控试用版**用于中控屏的地图、音乐和应用。首次安装可按[源码构建步骤](../README.md#从源码构建)生成开发版。已有 V58 中控版的用户可直接配置连接。
- 此次发布提供 [V58 源码与更新说明](https://github.com/Sykes-Shi/BmwDeck/releases/tag/v58-source)。此前 GitHub 上的 V46、V47 安装包已撤下。[历版更新记录](../CHANGELOG.md)
- 仪表导航属于独立试验。首次使用中控功能只需中控版。装有多个版本时，请为打算使用的那一版单独授权，一次只连接一版。

## 第一次连接

### 1. 准备手机和车辆

推荐 Android 14 或更新版本，最低支持安装的系统为 Android 12。打开手机的蓝牙、Wi-Fi 和移动数据。
如需在 V58 中控使用导航，请在这部手机上安装并启用**百度地图汽车版**。手机自己导航可继续使用百度地图手机版，两者可选择不同目的地。所需的音乐应用也装在手机上，并先单独打开确认可用。

车机需支持无线 CarPlay。项目主要围绕 iDrive 7 优化；已有一位社区用户反馈原车带无线 CarPlay 的 ID6 安卓直连成功，但车型、手机和软件版本未完整核实，不代表所有 ID6 或全部功能均兼容。

### 2. 启动 Shizuku

从 [Shizuku 官网](https://shizuku.rikka.app/) 获取并按其官方指南启动服务。无线调试激活时按系统要求连接 Wi-Fi；这一步不意味着必须先连接宝马热点。
确认 Shizuku 显示服务运行中。手机重启后通常需要重新启动服务。

### 3. 打开 BmwDeck 并授权

首次打开 BmwDeck 时，阅读应用中的免责声明，按界面提示操作。
在 Shizuku 授权弹窗中选择 BmwDeck 并允许。应用会检查服务和触控是否就绪，若仍提示未就绪，先返回 Shizuku 查看运行状态及授权列表。
按系统提示授予附近设备/蓝牙等所需权限。Android 12/12L 的 WLAN 流程可能还会请求位置权限。

### 4. 与宝马配对并选择设备

在宝马车机的「移动设备」或「连接设备」菜单打开无线 Apple CarPlay 配对，按两端提示确认蓝牙配对信息。如果此前已配对，可直接使用原设备记录。不同车型的菜单名称可能略有不同。
在手机 BmwDeck 的 **「连接 → 连接准备 → 选择设备」** 中选中自己的宝马。

### 5. 启动连接，选择是否传声音

在手机点击 **「启动连接」**。首次使用按提示允许「附近设备」，再在「连接声音」中选择一种方式。

- **车机播放声音**会把手机应用的播放声音送到车机。阅读 Android 的共享提示，确认本次授权。整机声音共享时，手机和中控两套路线上正在播放的导航提示都可能从车内扬声器响起。
- **仅画面**会保留投屏图像，手机应用的声音不会通过 BmwDeck 发送到车机。
- 勾选 **「记住本次选择」** 可沿用声音偏好。下次需要共享授权时，仍按 Android 当次的提示确认。

看到「等待车机回连」时，保持 BmwDeck 运行。如果车机尚未响应，在其「移动设备」列表选择这部手机的 Apple CarPlay 连接。按提示确认车机连接或手机加入热点，等待中控出现首页。宝马 Wi-Fi 用于本地投屏，地图和音乐上网通常还需要手机的移动数据。

### 6. 停车检查后再日常使用

先检查画面、触控或旋钮、音乐声音与联网。首页地图卡使用百度地图汽车版，轻点地图可放大。要使用「回家」「去公司」，先在汽车版中保存相应的地址。需要快捷键时再使用应用的 **「车机实体按键」** 校准，不同车机能上报的信号不同。
开启在线歌词是可选项：查询时会向 LRCLIB、网易云音乐曲库发送歌名和歌手，匹配不到时可能不显示歌词。
导航目的地应在出发前设置；行驶中不要操作应用、配置权限或观看视频。

## 每次上车的简版

确认 Shizuku 运行 → 开启蓝牙/Wi-Fi/移动数据 → 打开中控版 → 选择宝马 → 启动连接 → 按需开启声音并完成系统授权 → 等待车机画面。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 自行构建后安装失败或提示签名冲突 | 先核对手机上已有应用的包名和签名。按 README 构建的开发版使用独立包名，可保留已有中控版。 |
| Shizuku 已授权但不能连接 | 服务是否仍在运行、触控服务是否就绪；按应用提示重试，手机重启后重新启动 Shizuku。 |
| 找不到车机 | 确认原车无线 CarPlay、系统蓝牙配对，以及「选择设备」目标。 |
| 有画面但无声 | 确认本次已选「车机播放声音」并完成系统共享授权，再检查手机媒体音量和播放器状态。部分应用可能限制音频采集。 |
| 地图/音乐没网 | 确认移动数据开启。车机热点不等于互联网；VPN和手机厂商网络策略会影响联网，不建议盲目修改安全设置。 |
| 断连、黑屏或按键不对 | 停车后记录发生步骤并导出日志；不要通过刷写或 root 车机来盲目排查。 |

问题可提交至 [GitHub Issues](https://github.com/Sykes-Shi/BmwDeck/issues)。
请注明车型/年份、iDrive版本、手机型号/系统、APK版本、复现步骤及发生时间。上传截图或日志前遮盖精确位置、导航地址、设备标识和其他个人信息。

本教程按 V58 中控试用版的界面编写。继续使用 V47 的用户，声音选项可能显示为「开启声音」「仅视频（更流畅）」，导航设置也沿用 V47 的界面。
