# CarDeck-BMW 新手上手流程

> APK 安装在 **Android 手机**，不是宝马车机。车辆须已有可用的无线 CarPlay；本项目不会给没有 CarPlay 的车机解锁该功能。请全程停车配置，保留原车导航作为备用。

## 先选对版本

- 普通体验请选择 **中控试用版**：用于中控屏的地图、音乐与应用界面。
- **仪表测试版**是独立实验分支，不等于仪表地图已适配成功，新手不必安装。两版使用不同应用身份，需分别授权；一次只连接一版。
- [下载 V46 中控公开试用版](https://github.com/Sykes-Shi/CarDeck-BMW/releases/download/v46-public-preview/CarDeck-BMW-v46-public.apk)，在 [发布说明](https://github.com/Sykes-Shi/CarDeck-BMW/releases/tag/v46-public-preview) 核对 SHA-256 和证书指纹。不要把 Source code 压缩包当作 APK。
- 旧 Android Debug 签名的中控试用版无法覆盖升级到本次正式签名版。先保存需要的设置/日志，再卸载旧中控版并安装新包、重新授权；卸载会清除应用本地数据。新用户直接安装。本次不是对手机进行系统更新。

## 第一次使用：六步

### 1. 准备手机和车辆

推荐 Android 14 或更新版本。最低构建要求为 Android 12，但部分功能依赖较新系统，能安装不代表全部功能可用。
在手机安装百度地图及需要的音乐应用，先单独打开、登录并确认可正常使用。保持蓝牙、Wi-Fi 和移动数据开启。

车机需支持无线 CarPlay。项目主要围绕 iDrive 7 优化；已有一位社区用户反馈原车带无线 CarPlay 的 ID6 安卓直连成功，但车型、手机和软件版本未完整核实，不代表所有 ID6 或全部功能均兼容。

### 2. 启动 Shizuku

从 [Shizuku 官网](https://shizuku.rikka.app/) 获取并按其官方指南启动服务。无线调试激活时按系统要求连接 Wi-Fi；这一步不意味着必须先连接宝马热点。
确认 Shizuku 显示服务运行中。手机重启后通常需要重新启动服务。

### 3. 安装并授权 CarDeck-BMW

将中控试用 APK 安装到手机。首次打开先阅读应用中的免责声明，按界面提示操作。
在 Shizuku 授权弹窗中允许 CarDeck-BMW。应用会检查服务和触控服务是否就绪；显示未就绪时先处理提示，不要反复点击连接。
按系统提示授予附近设备/蓝牙等所需权限。Android 12/12L 的 WLAN 流程可能还会请求位置权限。

### 4. 与宝马配对并选择设备

在车机的移动设备/连接设备菜单与手机完成系统蓝牙配对，双方确认配对信息。不同车型菜单名称可能不同。
返回 CarDeck-BMW，点击 **「选择设备」**，选中自己的宝马；不要选其他手机或不认识的设备。

### 5. 启动连接，选择是否传声音

点击 **「启动连接」**：
- 要把音乐和导航声音送到车机，选 **「开启声音」**，并按提示授予本次系统投屏权限。该选项采集手机混合播放声音，不是麦克风；断开或撤销授权后停止采音。
- 选 **「仅视频（更流畅）」** 则不传车机声音，不能把这种情况下的无声当成故障。

等待应用尝试加入车机热点，并处理手机的热点连接确认及车机的 CarPlay 确认。不要在等待期间反复启动或随意切换 Wi-Fi。
宝马 Wi-Fi 主要用于本地投屏，地图和音乐联网仍可能依赖移动数据；已连 Wi-Fi 不代表有互联网。

### 6. 停车检查后再日常使用

先检查画面、触控/旋钮、百度地图、音乐声音与联网。需要快捷键时再使用应用的 **「车机实体按键」** 校准，不同车机能上报的信号不同。
开启在线歌词是可选项：查询时会向 LRCLIB、网易云音乐曲库发送歌名和歌手，匹配不到时可能不显示歌词。
导航目的地应在出发前设置；行驶中不要操作应用、配置权限或观看视频。

## 每次上车的简版

确认 Shizuku 运行 → 开启蓝牙/Wi-Fi/移动数据 → 打开中控版 → 选择宝马 → 启动连接 → 按需开启声音并完成系统授权 → 等待车机画面。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| APK 安装失败或提示签名冲突 | 核对下载版本和证书；旧调试包与正式签名包可能无法覆盖安装。不要急着卸载，先保留必要数据并阅读该版本升级说明。 |
| Shizuku 已授权但不能连接 | 服务是否仍在运行、触控服务是否就绪；按应用提示重试，手机重启后重新启动 Shizuku。 |
| 找不到车机 | 确认原车无线 CarPlay、系统蓝牙配对，以及「选择设备」目标。 |
| 有画面但无声 | 本次是否选了「开启声音」、授权是否有效、手机媒体音量和播放器状态。部分应用可能限制音频采集。 |
| 地图/音乐没网 | 确认移动数据开启。车机热点不等于互联网；VPN和手机厂商网络策略会影响联网，不建议盲目修改安全设置。 |
| 断连、黑屏或按键不对 | 停车后记录发生步骤并导出日志；不要通过刷写或 root 车机来盲目排查。 |
