# 一加 15 / iDrive 6 蓝牙测试

此次测试针对 V46 中控试用版启动时尝试断开车机蓝牙音频、随后投屏蓝牙连接失败的情况。测试包基于 V47 中控源码，默认开启「保留系统蓝牙连接（兼容测试）」。它先记录所选车机的蓝牙服务缓存，再直接尝试无线投屏连接。Android 返回明确错误码时会记入日志。

在停车状态下操作：

1. 在旧版 CarDeck 里停止连接，打开「CarDeck BMW 一加 ID6 测试」。测试包可单独安装，首次打开按提示授权蓝牙和 Shizuku。
2. 在「连接准备」中选择系统已配对的宝马车机，确认「保留系统蓝牙连接（兼容测试）」已开启。
3. 车机进入「通讯 → 管理移动设备 → 连接新设备 → Apple CarPlay」，确认后保持在该页面。手机点击「启动连接」，观察一分钟。车机操作可参照[宝马连接指南](https://faq.bmwusa.com/s/article/BMW-setting-up-Apple-CarPlay-bDaHU)。
4. 若仍失败，在本次连接过程中导出运行日志，并记录车机屏幕是仍在等配对、提示失败，还是没有 Apple CarPlay 入口。如果同一台车能用 iPhone 连通无线 CarPlay，也请注明。分享日志前请检查设备名和网络信息。

日志中的服务缓存可能过期。服务未列出、系统返回通用错误，均需结合车机页面和蓝牙连接方向判断。实车连接结果待复测。
