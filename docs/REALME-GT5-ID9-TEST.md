# 真我 GT5 / iDrive 9 联网与声音复测

测试包基于 V47 中控公测版，包名后缀为 `.realmegt5id9test`。可和公测版同时安装。复测时先断开原应用的投屏，在 GT5 测试版中单独完成 Shizuku、附近设备及本次投屏授权。

1. 停车，开启手机 WLAN 和移动数据。先用手机打开网页确认能上网，并准备一首已下载到手机的音乐作为声音对照。
2. 在测试版中选择已配对的宝马，点「启动连接」和「开启声音」，按提示允许系统投屏和加入热点。若车机热点已连接但手机无网，先选「重试专用连接」。投屏稳定后用手机浏览器重新加载同一网页。
3. 播放同一首本地音乐，记录声音是在车机还是手机上。按平时操作切到微信一次后回到播放器，并记下声音变化的时间。如果画面仍连着且手机端显示「点此恢复」，点它并完成授权，再检查车机是否恢复出声。联调期间避免在手机上开启系统录屏，以免影响采音授权。
4. 在复现当时保持连接，导出日志并注明网页结果、出声位置和时间。导出文件的 `FIELD-NET` 只描述 CarDeck 可见的网络，系统标为已校验也需要用网页对照。分享前遮盖设备标识、地址、热点及其他个人信息。

若空调栏挡住按钮，请在停车时用另一部手机拍完整车机画面，包含车机边框与空调栏。照片用于区分车机浮层叠盖与投屏画幅问题，避免把界面遮挡和网声故障混在一起。视频录屏暂停也单独记下发生在哪个设备和哪个应用。
